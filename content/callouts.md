# 콜아웃 / 알림 박스

GitHub 스타일 알림(admonition) 구문을 지원합니다.

> [!NOTE]
> 유용한 정보입니다. 사용자가 알아두면 좋은 내용을 강조합니다.

> [!TIP]
> 더 쉽게 하는 방법을 알려줍니다. 여러 줄로도 작성할 수 있고
> **굵게**나 `코드`도 포함됩니다.

> [!IMPORTANT]
> 목표 달성을 위해 꼭 알아야 하는 핵심 정보입니다.

> [!WARNING]
> 위험을 피하려면 즉시 주의해야 하는 중요한 내용입니다.

> [!CAUTION]
> 특정 행동의 부정적 결과나 위험을 경고합니다.

## 일반 인용과의 구분
