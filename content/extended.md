# 확장 구문

표준 마크다운을 넘어서는 편의 구문들을 지원합니다.

## 이모지 단축코드

`:shortcode:` 형식이 이모지로 변환됩니다: :rocket: :tada: :fire: :heart: :+1: :sparkles: :white_check_mark: :bug: :books: :coffee: :bulb:

작업 진행: :hourglass_flowing_sand: 진행 중 / :checkered_flag: 완료

코드 안에서는 변환되지 않습니다: `:rocket:` 그대로 유지.

## 하이라이트(마크)

==형광펜으로 강조한 텍스트== 처럼 `==...==`로 감싸면 강조됩니다.
**굵게** 와 ==강조== 를 함께 쓸 수도 있습니다.

## 각주

본문에 각주를 달 수 있습니다[^1]. 여러 개도 가능하고[^2], 같은 각주를 다시 참조할 수도 있습니다[^1].

[^1]: 첫 번째 각주입니다. **마크다운** 서식과 [링크](https://github.com)도 들어갑니다.
[^2]: 두 번째 각주. 페이지 하단에 정리되어 표시됩니다.

## 조합

- :pushpin: 중요한 항목은 ==강조==하고 각주로 부연[^note]
- 이모지 + 코드: :gear: `npm run build`

[^note]: 리스트 안의 각주도 정상 동작합니다.
