# 환영합니다 👋

이곳은 **모바일 최적화 마크다운 뷰어**입니다. 패턴 잠금을 해제하면 아래 목록의 문서들을 읽을 수 있습니다.

## 사용법

1. `content/` 폴더에 `.md` 파일을 추가하고 푸시하세요.
2. 푸시하면 GitHub Action이 `manifest.json`을 자동으로 갱신합니다.
3. 잠시 후 목록에 새 문서가 나타납니다.

## 지원하는 마크다운

- **굵게**, *기울임*, ~~취소선~~
- [링크](https://github.com)
- `인라인 코드`

> 인용문도 깔끔하게 표시됩니다.

    print("코드 블록은 가로 스크롤됩니다")
